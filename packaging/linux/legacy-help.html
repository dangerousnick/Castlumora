Advanced client access

This preview includes native library, user, transcoding, Live TV, plugin, network, task and log screens. Some advanced controls still need the compatible legacy Web client.

The upstream v12.4 release currently has no downloadable Web assets. This archive does not silently install an older incompatible client. See INSTALL_TEST_BUILD.md for attaching an existing compatible compiled Web distribution with CASTLUMORA_LEGACY_WEB_DIR.

Missing legacy assets limit access to inherited settings whose native screens are unfinished. This is a development preview, not full administrative parity.
